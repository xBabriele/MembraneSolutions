# MembraneSolutions

Il sistema Membrane Solutions Gestionale 4.0 è una piattaforma software progettata per il monitoraggio e la gestione dei processi produttivi industriali. L’obiettivo principale è quello di centralizzare in un unico ambiente tutte le informazioni provenienti dalla produzione, dai sensori e dalle attività operative.
Il sistema permette di ottenere una visione in tempo reale dello stato dell’impianto facilitando il controllo dei processi e migliorando l’efficienza operativa. L’integrazione dei dati consente agli utenti di prendere decisioni più rapide e informate.

L'accesso al sito tramite GitHub Pages (con il link: "https://xbabriele.github.io/MembraneSolutions/index.html") non consentirà il collegamento al database; pertanto le modifiche apportate sul sito e l'accesso non saranno salvati.

Prima di accedere al sito è consigliato leggere il manuale utente all'interno della cartella "docs", per comprendere meglio come funziona.

Tutte le informazioni relative al progetto, su come utilizzarlo e le informazioni tecniche, le trovate nella cartella "docs" della repository.
